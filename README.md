# Arena Strike

A browser-based 3D FPS prototype built with Three.js.

## Play
Open the deployed GitHub Pages site after the Pages workflow completes.

## Controls
- WASD: move
- Mouse: aim
- Left click: shoot
- R: reload
- Shift: sprint

## Phase 1
- 3D arena
- First-person camera
- Assault Rifle prototype
- Enemy target
- Health, ammo and score
- Respawn
